# 小程序兼容性评估（Web 端改版后）

> 评估对象：小程序（`BISHE-mobile`，`mobile` 分支）对接改版后的后端。
> 评估方式：对照小程序 `src/api/` 接口层与各页面代码，逐项核对改版后后端的接口与规则；旧接口用接口冒烟脚本验证过。
> 没有在微信开发者工具里实际运行小程序。

## 结论

**小程序可以继续使用。** 改版没有删除任何旧接口，小程序调用的全部接口（登录、注册、偏好、各模块的增删改查、
`/choice/getCurriculum`、`/score/getLine`、`/attendance/getPie`、`/course/recommend`、`/course/roomFree`、
`/warning/list`、`/warning/notify/{id}`）都还在，返回格式不变。变化集中在三类：

1. 有几条业务规则变严了，小程序里对应操作会收到错误提示（后端返回中文说明，小程序找不到错误码对应文案时直接显示它）；
2. 评教在两端分成了两套数据；
3. 改版新增的功能只在 Web 端。

## 一、规则变严的地方

| 场景 | 改版后的规则 | 小程序里的表现 | 建议改法 |
| --- | --- | --- | --- |
| 请假：编辑被驳回的申请 | 学生只能改、撤回自己**待审核**的申请（5027） | 请假页对「审核不通过」的申请也显示编辑按钮，重新提交会报错 | 编辑按钮只对「待审核」显示；被驳回的引导学生重新提交一条 |
| 请假：日期 | 最早补请 7 天前，一次最多连续 30 天（5028） | 超出范围时报错 | 日期选择器限制可选范围 |
| 选课 / 退选 | 已结课不能选（5023）、不能重复选（5024）、时间冲突（5026）；已结课或成绩已发布不能退（5025） | 提示后端的中文说明 | 可在列表上提前置灰；不改也能用 |
| 删除档案与账号 | 学院 / 专业 / 班级下面还有东西（5029）、有人选的课（5030）、还有课或带班的老师（5031）、还有选课的学生（5032）、当前登录的管理员自己（5033）、还排着课的教室（5034）都不能删 | 提示后端的中文说明 | 不改也能用 |
| 老师录成绩 | 走旧接口时**录入即发布**（不经过 Web 端成绩册的草稿），总评按课程上的四项权重计算 | 与 Web 端结果一致，只是老师在小程序里看不到「草稿 / 已发布」 | 如需草稿，改调 `/course/{id}/gradebook` |
| 学业预警提醒 | 老师只能提醒选了自己课的学生 | 老师的预警列表本来就只有自己的学生，不受影响 | 无需改动 |
| 防重复提交 | 按「同一份内容」判断，连续提交不同内容不再误报 | 只会更宽松 | 无需改动 |

另外两处是**修好的问题**，小程序同样受益：教室的新增与修改以前一直报「系统异常」，现在正常；
课程换任课教师后，选课记录上的教师会同步，老师在小程序的「我的学生」里能看到新接手课程的学生。

## 二、评教分成了两套数据

- 小程序的评教页写旧的 `comment` 表（按师生姓名关联，一段文字）；
- Web 端课程空间的「评价」写新的 `course_eval` 表（五个维度打分 + 文字，每人每课一次，对老师匿名展示）。

两边互不相通：老师在 Web 端课程空间里看不到小程序提交的评教（教务后台「网上评教」记录里能看到）。
建议小程序评教页改调 `GET / POST /course/{courseId}/evaluations`，与 Web 端统一。

## 三、只在 Web 端的新功能

| 功能 | 对小程序用户的影响 | 接入时要调的接口 |
| --- | --- | --- |
| 课堂签到（4 位签到码） | 老师用签到时，小程序里的学生没法签到，只能用 Web 端 | `POST /course/{id}/attendance/checkin` |
| 作业任务（老师布置 → 学生按任务提交 → 批改） | 小程序仍是「自由提交」作业，老师在 Web 端课程空间「作业」页的「旧版作业提交」里能看到并批改 | `/course/{id}/assignments` |
| 成绩册（草稿、发布）、成绩单 | 学生在小程序里只看得到已发布的成绩，与 Web 端一致 | `/course/{id}/gradebook/mine`、`/score/transcript` |
| 站内消息中心 | 小程序只收在线时的实时推送并存在本地；离线期间的消息存在服务端，小程序拿不到 | `GET /message/page`、`/message/unreadCount` |
| 课程资料、课程公告、成员 | 小程序看不到 | `/course/{id}/resources`、`/course/{id}/posts`、`/course/{id}/members` |
| 课程广场、月历请假、全局搜索、教务后台新页面、学期设置 | 小程序用各自原有的页面 | 按需 |

## 四、实时推送

改版新增了不带标题的「静默事件」（有人签到、交作业、发公告时让课程空间自动刷新）。
小程序 `utils/websocket.ts` 的 `handlePush` 遇到没有标题的消息直接忽略（`if (!msg || !msg.title) return`），
不会弹出空通知，无需改动。带标题的推送（成绩发布、作业批改、请假审核、学业预警）格式不变。

## 五、建议的改动顺序

1. 请假页：编辑按钮只对「待审核」显示；日期限制在 7 天前到 30 天内（避免用户碰到报错）。
2. 在 `locales` 的 `errors` 里补上 5013–5034 的英文文案（中文界面直接显示后端返回的说明即可）。
3. 评教改用 `/course/{id}/evaluations`；再按需要接入签到、作业任务和消息中心。
