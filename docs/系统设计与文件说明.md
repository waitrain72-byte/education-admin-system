# 教务管理系统 · 系统流程与文件说明

> 适用版本：Spring Boot 2.7.18 + Vue 3（Element Plus）+ uni-app（Vue 3）+ MySQL 5.7/8.x
> 配套文档：[数据库 ER 图](./数据库ER图.md)

---

## 一、系统概述与整体架构

系统为前后端分离的教育管理平台，覆盖管理员 / 教师 / 学生三类角色，包含三端交付：

| 端           | 目录                                    | 技术                                                             | 说明               |
| ------------ | --------------------------------------- | ---------------------------------------------------------------- | ------------------ |
| Web 管理端   | `vue/`                                  | Vue 3 + TypeScript + Element Plus + Pinia + vue-i18n + Vite      | 功能最全的管理后台 |
| 后端服务     | `springboot/`                           | Spring Boot 2.7 + MyBatis + PageHelper + MySQL + JWT + WebSocket | 统一 API 服务      |
| App 小程序端 | `BISHE-mobile/`（独立仓库 mobile 分支） | uni-app（Vue 3）编译到微信小程序                                 | 与 Web 端功能对齐  |

```
┌─────────────────┐   ┌─────────────────┐   ┌──────────────────┐
│  Web 管理端      │   │  App 小程序端    │   │  MySQL 数据库     │
│  vue (8080/dev)  │   │  BISHE-mobile   │   │  xm_educational  │
└────────┬────────┘   └────────┬────────┘   │  _manager        │
         │ /api 代理            │ 直连 9091   └────────▲─────────┘
         ▼                     ▼                      │
┌─────────────────────────────────────────────┐        │
│  Spring Boot 后端 (9091)                     ├────────┘
│  JwtInterceptor → PermissionAspect           │
│  → Controller → Service → Mapper(XML)        │
│         ↓ WebSocket ↓ 定时任务 ↓ AOP 日志     │
└─────────────────────────────────────────────┘
```

- 开发模式：Web 前端 Vite 将 `/api` 前缀代理到 `localhost:9091`（去除前缀）；小程序按 `.env.development` / `.env.production` 的 `VITE_API_BASE_URL` 直连 9091（`src/utils/config.ts` 读取，真机预览填电脑局域网 IP）。
- 生产模式：nginx 托管前端静态资源并将 `/api` 反代到后端；数据库口令、JWT 密钥、CORS 来源均支持环境变量注入。

### 2.3 Service 层（业务逻辑）

| 文件                                                                                                                                  | 职责                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BaseService`                                                                                                                         | 三类账号通用服务：登录（BCrypt 校验 + 连续失败锁定计数）、注册、修改资料（行级 + 字段级防越权、密码加密）、修改密码、重置密码（ADMIN 专用且不可重置自己）、头像引用清理                                     |
| `CrudService`                                                                                                                         | 业务实体通用服务：增删改查分页 + 数据隔离钩子 `applyDataScope`（selectAll/selectPage 统一经由，防止绕过分页接口拿全量数据）                                                                                 |
| `PermissionService`                                                                                                                   | RBAC 核心：权限判定（进程内缓存，授权保存后失效）、当前用户权限码集合、角色授权整体保存                                                                                                                     |
| `LoginProtectService`                                                                                                                 | 登录保护：连续失败 5 次锁定 10 分钟（错误码 4008）                                                                                                                                                          |
| `RecommendService`                                                                                                                    | 算法 A：基于物品的协同过滤课程推荐。以选课记录构建"学生×课程"矩阵，课程间余弦相似度 `sim(A,B)=\|U(A)∩U(B)\|/√(\|U(A)\|·\|U(B)\|)`，候选课得分=与已选课程相似度之和；冷启动（无选课/零相似）降级为按选课人数的热门推荐；已选课程自动排除 |
| `WarningService`                                                                                                                      | 算法 B：学业预警。风险指数 = 不及格占比×40 + 平均分差距×30 + 异常考勤率×30（缺勤计 1、迟到/早退计 0.5），≥60 高风险 / ≥30 中风险 / ≥10 低风险；数据范围按角色隔离（管理员全部、教师本人任课学生、学生本人） |
| `FileService`                                                                                                                         | 头像引用清理：资料更新导致头像变化时，统计三张账号表引用数，无人引用的旧文件删除（含路径穿越防护、中文名解码）                                                                                              |
| `ApplyService` / `HomeworkService`                                                                                                    | 请假审核 / 作业批改业务，变更后经 WebSocket 定点推送                                                                                                                                                        |
| `ChoiceService`                                                                                                                       | 选课核心：学分限定校验、上课时间冲突检测（同时间段已选则拒绝）、退课、我的课表组装                                                                                                                          |
| `ScoreService` / `AttendanceService` / `CommentService`                                                                               | 成绩（含学生维度数据隔离）/ 考勤（同时间段重复登记校验）/ 评教（重复评教校验）                                                                                                                              |
| `CourseService` / `CollegeService` / `SpecialityService` / `ClassesService` / `ExamplanService` / `RoomplanService` / `NoticeService` | 课程 / 学院 / 专业 / 班级 / 考试安排 / 教室安排 / 教务通知（新增广播）业务                                                                                                                                  |
| `DashboardService`                                                                                                                    | 数据大屏聚合统计：11 条查询汇总为一个接口，结果按 30 秒 TTL 进程内缓存（大屏由前端定时轮询，无需每次实时重算）；近 7 天登录趋势补零，今日/本周登录数由趋势汇总得出                                           |
| `LogService`                                                                                                                          | 操作 / 登录日志查询与批量删除                                                                                                                                                                               |

## 五、核心业务流程

### 5.1 登录认证流程

```
登录页（图形验证码 ← GET /captcha，Session 绑定）
  → POST /login {账号, 密码, 验证码, 角色}
     ├ 验证码校验（错误 → 402）
     ├ 登录保护（连续失败 5 次锁 10 分钟 → 4008，全部记登录日志）
     ├ BCrypt 密码比对（存量明文自动升级哈希）
     └ 成功：签发 JWT → 返回用户对象（含 token）
前端：token/角色/权限码写入 Pinia + localStorage
之后每个请求自动携带自定义头 token → JwtInterceptor 校验
```

### 5.2 RBAC 权限流程（三层联动）

```
登录成功 → GET /permission/my 拉取当前角色权限码集合 → 前端持久化
  ├ 路由层：router meta.roles + meta.permission 守卫校验（越权 → 403）
  ├ 菜单层：侧边栏按权限码/角色过滤显隐
  └ 按钮层：v-permission 指令控制操作按钮
每次接口请求：PermissionAspect 按数据库授权做服务端判定（ADMIN 放行，判定缓存化，授权保存即时失效）
```

### 5.3 以「课程」为中心的业务主链

```
学院 → 专业 → 班级 → 学生（基础档案链，数据大屏"学院人数"依赖此链）
教师 ──任教──> 课程（course.teacher_id，教师端只看本人课程）
选课（choice：学生×课程×教师）── 枢纽 ──┬→ 我的课表
                                      ├→ 成绩录入/查看
                                      ├→ 考勤登记/查看
                                      ├→ 作业提交/批改
                                      └→ 网上评教
请假独立成链：学生提交 → 管理员审核 → WebSocket 实时推送结果
```

### 5.4 实时通知流程（WebSocket）

```
登录成功 → 前端连接 ws://后端/ws/notice/{token}（连接时校验 token）
触发点：成绩录入或修改 / 请假审核 / 作业批改 / 学业预警提醒 → 定点推学生；学生提交作业 → 推教师；发布教务通知 → 全员广播
Web 端：ElNotification 右上角通知；App 端：静默入列不打断操作——「首页」tab 未读角标（回到首页清零）+ 消息中心按账号落库可回看，点消息直达对应页
断线：自动重连（Web 10 秒间隔 / App 指数退避 + 心跳保活 + 入站静默检测半开连接）
```

### 5.5 算法流程

**课程推荐（基于物品的协同过滤，RecommendService）**

```
选课记录 → 「学生×课程」0/1 矩阵
课程相似度：sim(A,B) = |U(A)∩U(B)| / √(|U(A)|·|U(B)|)
候选课得分 = Σ 与各已选课程的相似度
→ 取得分最高的 N 门（已选自动排除，附推荐理由）
冷启动（无选课/零相似）→ 降级为按选课人数的热门推荐
```

**学业预警（多指标加权评分，WarningService）**

```
风险指数(0~100) = 不及格占比×40 + 平均分差距×30 + 异常考勤率×30
  （异常考勤：缺勤计 1，迟到/早退计 0.5）
等级：≥60 高风险 / ≥30 中风险 / ≥10 低风险 / <10 正常
数据范围：管理员全部 / 教师本人任课学生 / 学生本人
触发动作：预警页查看 + 教师 / 管理员点「提醒」经 WebSocket 定点推送给学生（App 端进角标与消息中心，点开直达预警页）
```

### 5.6 文件上传下载流程

```
上传：前端直传 /files/upload（token + 权限 file:upload）
  → 扩展名白名单（图片/文档/压缩包 20 种）→ 内容 MD5 → 存储名 md5.ext（同内容去重）
  → 落盘 启动目录/files/ → 返回 /api/files/<md5>.<ext> 相对地址入库
下载：GET /files/{flag}（路径穿越防护 + 按扩展名返回 MIME）
清理：资料更新换头像时统计三表引用数，无人引用的旧文件自动删除
小程序：相册图片或微信聊天文件（PDF / Word / Excel 等）经 uni.uploadFile 上传，本地先拦截超 20MB 与不支持的类型；
        查看时图片预览，文档下载后 openDocument 打开，失败则复制链接
```

### 5.7 偏好多端同步流程

```
主题（light/dark/system）、语言（zh-CN/en-US）、自定义主题色（#RRGGBB 或空串）存账号表：
登录后 → GET /theme、/locale、/themeColor 拉取覆盖本地 → 修改后防抖 PUT 推送
Web 端同步 Element 暗色与自定义变量；App 端同步页面变量与原生导航/tabBar 配色
```

三项偏好机制相同（本地存储保证刷新不丢 + 防抖推送 + 拉取时防回环），两端都已实现：

| 偏好 | 字段 | Web 端 | 小程序端 |
| --- | --- | --- | --- |
| 深浅模式 | `theme` | ✅ | ✅ |
| 界面语言 | `locale` | ✅ | ✅ |
| 自定义主题色 | `theme_color` | ✅ 任意取色 + 8 个预设 | ✅ 8 个预设（小程序没有原生取色器；Web 端选的任意颜色照常生效） |

自定义主题色的落地方式与前两项不同：它不是切换预设样式，而是在运行时按所选颜色
**计算出完整的 Element Plus 色阶**（`--el-color-primary` 及其 `light-3/5/7/8/9`、`dark-2`），
以内联样式写在 `<html>` 上——内联优先级高于 `:root` 与 `html.dark` 两条规则，无需处理选择器权重；
恢复默认时移除这些内联属性即可自动回落到样式表中的内置配色。
深色模式下先把基色提亮 20% 再派生，否则深色系自定义色在暗背景上对比度不足。
`index.html` 的防闪烁脚本会在应用挂载前先铺上基色，避免首屏闪现默认色。

小程序端用同一套算法（`src/utils/themeColor.js`，与 Web 端逐位一致，有跨端同值测试）。小程序不能在运行时改 `page` 根样式，
改由全局混入给每个页面根节点绑定 `:style="themeStyle"` 注入 CSS 变量（新增页面也要绑定）；原生导航栏与 tabBar 文字颜色
通过 `setNavigationBarColor` / `setTabBarStyle` 同步，tabBar 图标是图片、保持默认色；退出登录时复位，避免下一个账号看到上一个账号的配色。

| ---- | --------------------------------------------------------------------------------------------------------- |
| 认证 | JWT（密钥/时效可配置）、BCrypt 密码哈希（明文自动升级）、图形验证码、连续失败锁定                         |
| 鉴权 | RBAC 三层（路由/菜单/按钮）+ 服务端切面逐请求判定 + token 自定义头                                        |
| 输入 | MyBatis 全 `#{}` 预编译（禁 `${}`、禁 allowMultiQueries）、XSS 反序列化中和、上传扩展名白名单 + 20MB 上限 |
| 文件 | MD5 重命名、下载路径穿越防护、按扩展名返回 MIME                                                           |
| 越权 | 行级（非管理员仅本人）+ 字段级（自助更新白名单）双层防护                                                  |
| 审计 | 操作日志（AOP 自动、密码脱敏）+ 登录日志（成功/失败），90 天自动清理                                      |
| 小程序 | 路由拦截器 + 页面 `onShow` 兜底的登录拦截；本地缓存与消息按「角色-id」隔离，密码类字段不写入本地存储；`RELEASE=1` 构建拒绝非 HTTPS / 局域网地址 |
