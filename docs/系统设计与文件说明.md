# 教务管理系统 · 系统流程与文件说明

> 适用版本：Spring Boot 2.7.18 + Vue 3（Element Plus）+ uni-app（Vue 3）+ MySQL 5.7/8.x
> 配套文档：[数据库 ER 图](./数据库ER图.md)

---

## 一、系统概述与整体架构

系统为前后端分离的教务平台，覆盖管理员 / 教师 / 学生三类角色，包含三端交付：

| 端           | 目录                                    | 技术                                                             | 说明                                         |
| ------------ | --------------------------------------- | ---------------------------------------------------------------- | -------------------------------------------- |
| Web 端       | `vue/`                                  | Vue 3 + TypeScript + Element Plus + Pinia + vue-i18n + Vite      | 「课程空间」式界面：师生按课程组织，管理员进教务后台 |
| 后端服务     | `springboot/`                           | Spring Boot 2.7 + MyBatis + PageHelper + MySQL + JWT + WebSocket | 统一 API 服务                                |
| App 小程序端 | `BISHE-mobile/`（独立仓库 mobile 分支） | uni-app（Vue 3）编译到微信小程序                                 | 与 Web 端同步改版，调用同一套接口             |

```
┌─────────────────┐   ┌─────────────────┐   ┌──────────────────┐
│  Web 端          │   │  App 小程序端    │   │  MySQL 数据库     │
│  vue (8080/dev)  │   │  BISHE-mobile   │   │  xm_educational  │
└────────┬────────┘   └────────┬────────┘   │  _manager_v2     │
         │ /api 代理            │ 直连 9091   └────────▲─────────┘
         ▼                     ▼                      │
┌─────────────────────────────────────────────┐        │
│  Spring Boot 后端 (9091)                     ├────────┘
│  JwtInterceptor → PermissionAspect           │
│  → Controller → Service → Mapper(XML/注解)   │
│     ↓ WebSocket ↓ 定时任务 ↓ AOP 日志 ↓ 启动迁移 │
└─────────────────────────────────────────────┘
```

- 开发模式：Web 前端 Vite 将 `/api` 前缀代理到 `localhost:9091`（去除前缀）；小程序按 `.env.development` / `.env.production` 的 `VITE_API_BASE_URL` 直连 9091（`src/utils/config.ts` 读取，真机预览填电脑局域网 IP）。
- 生产模式：nginx 托管前端静态资源并将 `/api` 反代到后端；数据库口令、JWT 密钥、CORS 来源均支持环境变量注入。
- 业务时间：后端统一用北京时间的 `Clock`（`common/AppTime` + `ClockConfig`），接口返回服务器当前时间，前端的「正在上课」「签到倒计时」都按它校准，不依赖访问者电脑的时区和时钟。

**Web 端的组织方式**：顶部导航只有「首页 / 课程 / 日程 / 消息」（管理员多一个「教务后台」）。学生、教师围绕课程活动——
「课程」里每门课是一个课程空间（概览、签到、作业、成绩、评价、资料、成员七个分页），选课在课程广场，
课表与请假在日程；管理员的维护工作集中在教务后台（左侧栏分「教学 / 教学记录 / 档案 / 系统」四组）。
`Ctrl K` 全局搜索可以直接跳到课程、通知、学生、教师和各页面。

## 二、后端文件地图（springboot/src/main/java/com/example/）

### 2.1 启动与横切关注点

| 文件                                                                 | 职责                                                                                                        |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `SpringbootApplication.java`                                         | Spring Boot 启动类                                                                                          |
| `common/AppTime`、`common/config/ClockConfig`                        | 业务时钟：固定按北京时间（Asia/Shanghai）计算「今天」「现在」，单测可注入固定时钟                          |
| `common/annotation/RequirePermission`                                | 权限注解：类上声明模块（按请求方式推导 view/manage），方法上声明完整权限码                                  |
| `common/annotation/NoRepeatSubmit`                                   | 防重复提交注解：关键写接口在间隔内拒绝**同一份内容**的重复请求                                             |
| `common/config/JwtInterceptor`                                       | 登录拦截器：校验 JWT、解析当前用户；放行 /login、/captcha、/files/\*\* 等白名单                             |
| `common/config/PermissionAspect`                                     | RBAC 切面：拦截全部 Controller，解析权限码交 PermissionService 判定（判定结果进程内缓存，授权变更即时失效） |
| `common/config/ControllerLogAspect`                                  | 操作日志切面：自动记录所有非 GET 请求（密码脱敏、超长截断）                                                 |
| `common/config/RepeatSubmitAspect`                                   | 防重复提交切面：键为「用户 + 接口 + 请求内容指纹」，连点同一份内容被拦，内容不同的连续操作放行；过期记录自动清理 |
| `common/config/CorsConfig`                                           | CORS 过滤器：来源白名单（配置化）+ 允许凭证（Session 需要）                                                 |
| `common/config/XssConfig`                                            | Jackson 反序列化中和脚本标签（XSS 防御）                                                                    |
| `common/config/WebConfig`                                            | 注册 JwtInterceptor 及其白名单                                                                              |
| `common/config/WebSocketConfig`                                      | 注册 WebSocket 服务端点                                                                                     |
| `common/config/Knife4jConfig`                                        | 接口文档（/doc.html）                                                                                       |
| `common/config/SchemaMigration`                                      | 启动时增量迁移（幂等）：查 information_schema，旧库缺表就建表、缺列就 ALTER、缺权限点就补并授权、缺学期参数就写默认值；失败只记日志并给出手动 SQL，不阻止启动 |
| `common/Result`                                                      | 统一返回体 `{code, msg, data}`                                                                              |
| `exception/CustomException`、`GlobalExceptionHandler`                | 业务异常与全局异常处理（统一错误码返回）                                                                    |
| `common/enums/ResultCodeEnum`、`RoleEnum`、`SegmentEnum`、`WeekEnum` | 错误码 / 角色 / 上课大节 / 星期 枚举                                                                        |
| `common/Constants`                                                   | token 请求头名、默认密码等常量                                                                              |

### 2.3 Service 层（业务逻辑）

| 文件 | 职责 |
| --- | --- |
| `BaseService` | 三类账号通用服务：登录（BCrypt 校验）、新增（账号在三张表间全局唯一）、修改资料（行级 + 字段级防越权）、改密、重置密码、删除前检查钩子 `beforeDelete`、批量删除逐条检查 |
| `AdminService` / `TeacherService` / `StudentService` | `BaseService` 的三个子类：各自的删除前检查（管理员不能删自己、还有课或带班的老师不能删、有选课的学生不能删）与本人可改字段的白名单；学生注册在 `StudentService` |
| `CrudService` | 业务实体通用服务：增删改查分页 + 数据隔离钩子 `applyDataScope`（selectAll/selectPage 统一经由） |
| `AccountLookupService` | 按账号判断登录身份；三张账号表之间的用户名查重 |
| `WorkbenchService` / `SearchService` / `ConfigService` | 分角色首页（今天的课、下一节、待办、学分绩点、出勤率、预警、管理员指标）/ 全局搜索 / 学期参数与教学周推算 |
| `MessageService` | 站内消息：落库 + WebSocket 推送（控制器在事务提交后调用，回滚了就不会误发） |
| `CourseSpaceService` | 课程空间公共部分：当前登录人与课程的关系（教师 / 学生 / 管理员 / 访客）、概览、成员、公告、课程事件广播 |
| `AttendanceSessionService` | 课堂签到：发起（4 位码、限时）、签到（输错 5 次锁定）、结束时给没签到的补「缺勤」（请假中的记「请假」）；`task/AttendanceSessionTask` 每 20 秒收尾过期场次 |
| `AssignmentService` / `HomeworkService` | 作业任务与提交、批改（分数不超过满分，学生不能自己改分）；旧版作业接口的越权防护 |
| `GradeCalculator` / `GradebookService` | 总评计算（考勤分、作业分按记录折算，四项按权重加权）/ 成绩册的保存、发布、撤回与学分记账（只累加已发布且及格的课程） |
| `ScoreService` / `TranscriptService` | 旧版成绩接口（学生只看已发布的）/ 学生成绩单（所有课的已发布成绩、平均学分绩点、加权平均分） |
| `CourseEvalService` / `CourseResourceService` / `UploadedFiles` | 课程评价（每人每课一次，汇总对教师匿名）/ 课程资料 / 附件地址校验（只认本系统上传的文件） |
| `EnrollmentService` / `CourseSquareService` / `ChoiceService` | 选课规则（已结课不能选、不能重复选、满员行锁拦截、时间冲突；退选要求没结课且成绩没发布）/ 课程广场 / 旧版选课接口 |
| `ScheduleService` | 周课表、月历、某段日期要上的课（请假预览与批准时补记考勤用） |
| `ApplyService` | 请假：学生只能以自己的名义提交、只改自己待审核的；最早补请 7 天前、一次最多 30 天；批准时把已过去日子的考勤记为「请假」 |
| `CourseService` / `RoomplanService` | 课程（换任课教师同步选课记录、重开课查教室占用、有人选的课不能删）/ 教室（编号唯一、改编号同步课程、排着课的不能删） |
| `OrgService` / `PeopleService` / `CollegeService` / `SpecialityService` / `ClassesService` | 组织架构树与删除前检查 / 人员分页查询 / 学院、专业、班级 |
| `RecommendService` | 算法 A：基于物品的协同过滤课程推荐（余弦相似度；冷启动降级为热门） |
| `WarningService` | 算法 B：学业预警（不及格占比×40 + 平均分差距×30 + 异常考勤率×30）；提醒范围检查 |
| `PermissionService` / `LoginProtectService` / `LogService` / `FileService` / `DashboardService` / `NoticeService` / `ExamplanService` / `CommentService` / `AttendanceService` | RBAC 判定 / 登录失败锁定 / 日志 / 头像引用清理 / 数据大屏（30 秒缓存）/ 通知 / 考试安排 / 旧版评教 / 旧版考勤 |

## 五、核心业务流程

### 5.1 登录认证流程

```
登录页（图形验证码 ← GET /captcha，Session 绑定）
  → POST /login {账号, 密码, 验证码}（不选身份；遇到 5012 时再带上用户选的 role）
     ├ 登录保护（连续失败 5 次锁 10 分钟 → 4008，全部记登录日志）
     ├ 验证码校验（错误 → 402，不计入账号失败次数）
     ├ 按账号判断身份（三张账号表里账号全局唯一；历史数据里同名同密码时返回 5012，前端再让用户选一次）
     ├ BCrypt 密码比对（存量明文自动升级哈希）
     └ 成功：签发 JWT → 返回用户对象（含 token）
前端：token/角色/权限码写入 Pinia + localStorage，进分角色首页
之后每个请求自动携带自定义头 token → JwtInterceptor 校验
```

### 5.2 RBAC 权限流程（三层联动）

```
登录成功 → GET /permission/my 拉取当前角色权限码集合 → 前端持久化
  ├ 路由层：router meta.roles + meta.permission 守卫校验（越权 → 403）
  ├ 导航层：顶部导航与教务后台侧栏按角色裁剪
  └ 按钮层：v-permission 指令控制操作按钮
每次接口请求：PermissionAspect 按数据库授权做服务端判定（ADMIN 放行，判定缓存化，授权保存即时失效）
服务层再做行级判断：老师只能管自己的课，学生只能以自己的名义选课、请假、交作业
```

### 5.3 以「课程」为中心的业务主链

```
学院 → 专业 → 班级 → 学生（档案链；教务后台「组织架构」一棵树维护）
教务后台开课（三步向导：基本信息 → 时间与教室 → 确认）── 课程 ── 任课教师
学生在课程广场选课（满员、时间冲突、已结课拦截）→ choice（学生 × 课程 × 教师）
                                        │
                     课程空间（每门课一个）─┼→ 签到：老师发起 4 位码 → 学生签到 → 结束时补记缺勤 / 请假
                                        ├→ 作业：老师布置任务 → 学生提交 → 老师批改（推送学生）
                                        ├→ 成绩：考勤分、作业分自动折算 + 平时、期末分 → 成绩册草稿 → 发布（推送学生，计入学分）
                                        ├→ 评价：学生五维打分（对老师匿名）
                                        └→ 资料、公告、成员
日程：选课 + 学期参数 → 周课表 / 月历；月历选日期请假 → 教务后台看板审批 → 批准时补记请假考勤
```

### 5.4 实时通知流程（WebSocket + 站内消息）

```
登录成功 → 前端连接 ws://后端/ws/notice/{token}（连接时校验 token）
有标题的推送（成绩发布、作业批改、请假审核、学业预警提醒、课程公告等）：
  MessageService 先落库 message 表（消息中心可回看、记未读），再推送在线的人；Web 端右上角通知并刷新未读数
静默事件（不带标题）：有人签到、交作业、发公告时推给这门课的成员，课程空间对应分页自动刷新，不打扰用户
发布全校通知 → 全员广播
断线：自动重连（Web 10 秒间隔 / App 指数退避 + 心跳保活）
```

### 5.5 算法流程

**课程推荐（基于物品的协同过滤，RecommendService）**

```
选课记录 → 「学生×课程」0/1 矩阵
课程相似度：sim(A,B) = |U(A)∩U(B)| / √(|U(A)|·|U(B)|)
候选课得分 = Σ 与各已选课程的相似度
→ 取得分最高的 N 门（已选自动排除，附推荐理由；课程广场只展示有理由的推荐）
冷启动（无选课/零相似）→ 降级为按选课人数的热门推荐
```

**学业预警（多指标加权评分，WarningService）**

```
风险指数(0~100) = 不及格占比×40 + 平均分差距×30 + 异常考勤率×30
  （异常考勤：缺勤计 1，迟到/早退计 0.5；只算已发布的成绩）
等级：≥60 高风险 / ≥30 中风险 / ≥10 低风险 / <10 正常
数据范围：管理员全部 / 教师本人任课学生 / 学生本人
触发动作：学生首页显示本人风险；教师首页「需要关注的学生」可一键提醒（只能提醒自己课上的学生）
```

**总评与学分（GradeCalculator / GradebookService）**

```
考勤分 = 每次考勤按 正常/请假 100、迟到/早退 80、缺勤 0 取平均（没有记录记 100）
作业分 = 每个作业任务 批改分 ÷ 满分 × 100，过了截止没交记 0，取平均
总评 = 考勤分×考勤权重 + 作业分×作业权重 + 平时分×平时权重 + 期末分×期末权重（四项权重合计 100）
发布 → 学生可见；已发布且 ≥60 分的课程学分计入学生的已修学分；撤回发布扣回
平均学分绩点：及格时绩点 =（成绩 − 50）÷ 10（最高 5.0），不及格记 0，按学分加权
```

### 5.6 文件上传下载流程

```
上传：前端直传 /files/upload（token + 权限 file:upload）
  → 扩展名白名单（图片 6 种、文档 9 种、压缩包 3 种，共 18 种）→ 内容 MD5 → 存储名 md5.ext（同内容去重）
  → 落盘 启动目录/files/ → 返回 /api/files/<md5>.<ext> 相对地址入库
作业附件、课程资料只接受本系统上传得到的 /api/files/ 地址（防止填外链）
下载：GET /files/{flag}（路径穿越防护 + 按扩展名返回 MIME）
清理：资料更新换头像时统计三表引用数，无人引用的旧文件自动删除
```

### 5.7 偏好多端同步流程

```
主题（light/dark/system）、语言（zh-CN/en-US）、自定义主题色（#RRGGBB 或空串）存账号表：
登录后 → GET /theme、/locale、/themeColor 拉取覆盖本地 → 修改后防抖 PUT 推送
Web 端同步 Element 暗色与自定义变量；App 端同步页面变量与原生导航/tabBar 配色
```

自定义主题色在运行时按所选颜色**计算出完整的 Element Plus 色阶**（`--el-color-primary` 及其 `light-3/5/7/8/9`、`dark-2`），
以内联样式写在 `<html>` 上；恢复默认时移除这些内联属性即可回落到内置配色。深色模式下先把基色提亮 20% 再派生。
小程序端用同一套算法（`src/utils/themeColor.js`，与 Web 端逐位一致，有跨端同值测试）。

## 七、安全设计要点

| 层   | 措施                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------- |
| 认证 | JWT（密钥/时效可配置）、BCrypt 密码哈希（明文自动升级）、图形验证码、连续失败锁定                         |
| 鉴权 | RBAC 三层（路由/导航/按钮）+ 服务端切面逐请求判定 + token 自定义头                                        |
| 输入 | MyBatis 全 `#{}` 预编译（禁 `${}`、禁 allowMultiQueries）、XSS 反序列化中和、上传扩展名白名单 + 20MB 上限 |
| 文件 | MD5 重命名、下载路径穿越防护、按扩展名返回 MIME；作业附件与课程资料只认本系统上传的地址                    |
| 越权 | 行级（老师只管自己的课、学生只操作自己的数据）+ 字段级（自助更新白名单）；学生不能替别人选课、请假、改分   |
| 一致性 | 删除保护（错误码 5029–5034）与级联同步（换任课教师、教室改编号），避免孤儿数据                          |
| 审计 | 操作日志（AOP 自动、密码脱敏）+ 登录日志（成功/失败），90 天自动清理                                      |
| 小程序 | 路由拦截器 + 页面 `onShow` 兜底的登录与角色拦截；本地缓存按「角色-id」隔离，密码类字段不写入本地存储；`RELEASE=1` 构建拒绝非 HTTPS / 局域网地址 |
